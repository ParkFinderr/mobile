# Update Progress Skill

This skill ensures that whenever you make changes, complete tasks, or implement features, you must always update the progress report in the `progres/` directory to keep it accurate and up to date.

## Instructions:
1. Locate the progress report in `progres/progres.md`.
2. After completing a task or code changes, edit `progres/progres.md` to reflect:
   - What has been completed.
   - What features or tasks are currently in progress or remaining.
   - Update the status (e.g. Selesai vs Perlu perbaikan vs Belum dimulai).
3. Keep the report brief, clear, and in Markdown.
